# 🏎️ F1 Dashboard

Dashboard interactif consacré à la Formule 1, développé avec **Python et Streamlit**, permettant d'explorer et de visualiser les statistiques historiques de la F1.

Ce projet personnel a été réalisé dans le cadre de ma **formation de Data Analyst**, afin de mettre en pratique mes compétences en manipulation, analyse et visualisation de données.

## 📊 Fonctionnalités

- **Statistiques des pilotes** : nombre de courses, victoires, podiums, points et autres statistiques.
- **Comparaison de pilotes** : comparaison des performances de plusieurs pilotes.
- **Sélection des saisons** : exploration des résultats selon les années.
- **Résultats des Grands Prix** : visualisation des positions d'arrivée des pilotes, course après course.
- **Graphiques interactifs** : visualisation et comparaison des données à l'aide de graphiques dynamiques.

🚧 **Projet en cours de développement** : de nouvelles fonctionnalités et visualisations seront ajoutées progressivement.

## 🛠️ Technologies utilisées

- **Python** — Traitement des données
- **Pandas** — Manipulation et analyse des données
- **Streamlit** — Création de l'application web interactive
- **Plotly** — Visualisation des données

## 📁 Source des données

Les données utilisées proviennent de [F1DB](https://github.com/f1db/f1db), une base de données open source regroupant les statistiques historiques de la Formule 1 depuis 1950.

## 🚀 Installation

Cloner le dépôt GitHub, puis installer les dépendances :

```bash
pip install -r requirements.txt
```

Lancer l'application :

```bash
streamlit run app.py
```
